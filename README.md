# 4-апта: uniform + delta time

Үшбұрыш шеңбер бойымен қозғалады, өлшемі пульсациялайды, қозғалыс кадр жиілігіне тәуелсіз.

## Құрастыру (MinGW)

```
g++ -std=c++17 main.cpp glad/src/gl.c -Iglad/include -Iinclude -Llib-mingw-w64 -lglfw3 -lgdi32 -o main.exe
```

## Басқару

| Перне | Әрекет |
|---|---|
| W / S | айналу жылдамдығы + / − (0.1 … 10 рад/с) |
| Q / E | орбита радиусы − / + |
| R | бастапқы күйге қайтару |
| Esc | шығу |

## 1-тапсырма: dt-ны алып тастау

`angle += speed * dt;` орнына `angle += 0.02f;` қойып, `glfwSwapInterval(0)` арқылы VSync өшірдім.
Менің компьютерімде үшбұрыш өте жылдам айналды (FPS бірнеше мың болды), ал көршімнің компьютерінде
FPS басқа болғандықтан жылдамдығы мүлде басқаша болды. Себебі бұрыш әр **кадрда** 0.02-ге өседі,
яғни секундына `0.02 × FPS` радиан — жылдамдық компьютердің қуатына тәуелді болып қалады.
`dt`-ға көбейткенде өсім секундқа шаққанда бірдей болады, сондықтан `speed = 1.5f` — бұл
**секундына 1.5 радиан**, кадрға емес.

## 3-тапсырма: неге жеделдетуге де dt керек?

`speed += 2.0f;` десек, W басылып тұрғанда жылдамдық әр кадрда өседі — 1000 FPS-те 60 FPS-ке
қарағанда 16 есе тез. `speed += 2.0f * dt;` болса, жылдамдық секундына 2 рад/с-ке өседі, FPS-ке
қарамастан бірдей.

## Қосымша

- Жылдамдық `std::clamp` арқылы 0.1 … 10.0 аралығында шектелген
- R — бастапқы күйге қайтару
- Орбита радиусы `uRadius` uniform, Q/E арқылы реттеледі
- Екі объект: біреуі сағат тіліне қарсы, екіншісі сағат тілімен (кішірек орбитада)
